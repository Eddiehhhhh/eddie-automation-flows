# Cloud weekly bundle

`scripts/cloud_weekly_bundle.py` materializes an already reviewed three-tab weekly synthesis in a clean, isolated private-vault checkout. It does not invoke a model, publish to GitHub, edit Wiki or inspect the Mac workspace. The authorized cloud task supplies private three-tab JSON outside the checkout, a fixed source commit and the actual Shanghai run date. The script audits all registered sources without the old per-source cap, writes at most the 16 approved report/index/state paths, preserves historical Observatory periods and checks its own outputs. `--verify-existing` checks a generated bundle without modifying it.

The checkout commit must equal `--source-sha`. The durable run key is a digest of `weekly:<period>:<source SHA>:cloud`; an already published key stops generation. The caller must still compare the complete target path/blob manifest with the latest private `main`, make one commit with the exact approved paths, and push non-force only while the read parent remains the remote head. A race requires fresh target and run-key reads, never a blind retry. After publishing, read back the three tabs, receipt, indexes, frontend, state and phone-visible result. Keep the private page input and stdout out of public Actions artifacts.

The legacy `iteration_closeout.py` no longer auto-upserts Wiki from source-count heuristics. Its four-source closeout and workspace intake are not a substitute for cloud synthesis. Only Eddie-confirmed facts may enter personal Wiki through a separate version-checked transaction. A partial System 4.0 status is intentional when source or display evidence is missing.
